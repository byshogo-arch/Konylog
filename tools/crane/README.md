# ラフター吊り荷計算（KONYLOG TOOLS）

ラフテレーンクレーン（ラフター）のメーカー公表「定格総荷重表」を取り込み、
作業半径・ブーム長さ・アウトリガ張出幅・旋回方向（前方／側方／後方）・ジブごとに
「何mで何t吊れるか」「ブームは何度か（目安）」を図で確認する静的Webツール。

- 画面：`index.html`（ビルド不要。ファイルを直接開いても、静的ホスティングでも動く）
- ロジック：`app.js`（素のJavaScript）。PDF出力だけ `vendor/` の html2canvas 1.4.1・jsPDF 2.5.1（MIT）を、
  ボタンを押したときに読み込む（サイト内に同梱しているので電波がなくても動く）
- データ：`data/src/<id>.json`（機種ごとの元データ。形式は `data/SCHEMA.md`） → `node scripts/build-data.mjs` で
  `data/index.js`（機種一覧）と `data/models/<id>.js`（機種データ、選択時に読み込み）を生成

## 操作のポイント

- 側面図・平面図のドラッグで作業半径を動かすと、その条件（張出幅・旋回方向・ブーム長さ・ジブ）で表に値がある
  最大の作業半径で止まる。側面図に「最大半径」の線、平面図に届く範囲の輪郭（点線）を表示。数値入力は制限しない。
- 「PDFで保存（計算書）」：計算条件・結果の内訳・負荷率・側面図／平面図・注意事項・押印欄（1枚目）、
  向き別の能力・使用した定格総荷重表（採用セル強調）・車両と公道判定・出典・同じ条件を開くURL（2枚目）の
  A4・2ページのPDFを保存する。PDFが作れない環境ではブラウザの印刷画面（「PDFに保存」を選ぶ）を開く。

## 計算のルール（安全側）

- 表の値は **定格総荷重**（フック・つり具込み）。
  `定格荷重 = 定格総荷重 − フック質量`、`吊れる荷 = 定格荷重 − 玉掛け用具`。
- 安全率（なし／0.9／0.85／0.8／任意）を選ぶと `吊れる荷 = 定格総荷重 × 安全率 − フック − 玉掛け用具` で判定。
- 表の行（作業半径）・列（ブーム長さ）の中間は、前後の値のうち **小さい方** を採用。
  表に値がない（届かない・近すぎる）場合は「吊れません」。
- 旋回方向：中間・最小張出では側方は張出幅ごとの表、前方・後方（各機種の注意事項の±a°/α°/β°）は
  最大張出（または前方性能表）の値。アウトリガ不使用時は前方（±1〜2°）と360°。
- ジブ：半径基準の表（タダノ現行機など）は作業半径で、ブーム角度基準の表は角度の行（安全側）で判定。
- ブーム角度・揚程は作業半径からの幾何計算による目安（ブームのたわみ・取付位置の差は含まない）。
- 公道走行：走行時の寸法・重量を車両制限令の一般的制限値（幅2.5m・長さ12m・高さ3.8m・総重量20t・
  軸重10t・隣接軸重18〜20t・輪荷重5t・最小回転半径12m）と比較し、超えれば特殊車両通行許可が必要と表示。

## データの出典と確認方法

各機種の出典PDF（タダノ／加藤製作所の公式サイト、タダノの中古車部門の仕様書）は
JSONの `sources`、画面の「出典」欄に記載。
抽出はPDFの文字座標から表を再構成（画像のみのPDFはOCR後に画像と照合）し、次の確認を行っている。

1. 構造・妥当性チェック（`python3 -I scripts/validate.py data/src/*.json`）：半径の昇順、半径とともに荷重が増えない、
   側方の表が最大張出の表を超えない、狭い張出が広い張出を超えない、ゾーン指定の参照先が存在する など
2. 主要諸元の能力値（例「16.4mブーム 18,000kg×5.0m」）と表のセルの突き合わせ
3. 全ての表を出典PDFの画像と行・列ごとに目視照合（各JSONの `verification` に記録）
4. 抽出とは別の担当による二重チェック（2026-11-06）：原本PDFから独自に表を読み取り、24機種の全セル
   （荷重・半径/角度・角度範囲・巻掛本数・フック）を照合して値の不一致なし。画像のみのGR-160Nは300dpiの
   目視とOCRで全セルを照合。二重チェックで見つかった解釈上の点（＊印セルの巻掛本数、前方特別性能はAML設定時のみ、
   アウトリガ不使用の前方範囲は±1°、SL-850の80tは前方±15°のみ）はアプリ側で安全側に反映済み。

## 収録機種

- タダノ：GR-130NL / GR-130N（4.9t）と各2ウインチ仕様、GR-160N（G5）、GR-250N（G5）、eGR-250N、GR-600N、
  GR-700N（G5）、GR-1000N、旧型 GR-250N（G4）・GR-350N・GR-500N（前方特別性能）
- 加藤製作所：MR-130RfⅡ / MR-130RfⅡM（4.9t）、MR-200Rf、MR-250Rf、SR-250RfⅡ、SL-250RV、MR-350RfⅡ、
  SL-500RfⅢ、SL-600RfⅢ、SL-750RfⅢ、SL-850RfⅢ（カウンタウエイト付）
- 未収録：GR-1450EX（公開資料に定格総荷重表なし）、SR-250HV（公開資料が画像パンフレットのみ）
- GR-600N・GR-1000Nは公開スペックシートに最大張出の表しかないため、中間・最小張出は未収録（画面に注意表示）

**計画・打合せ用の目安です。実作業は必ず実機の定格総荷重表と過負荷防止装置（AML/ACS）に従ってください。**
