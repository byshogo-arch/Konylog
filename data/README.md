# 建材相場ボードのデータ

`souba.html`（建材相場ボード）とトップページの入口パネルが読むデータです。

| ファイル | 中身 | 更新のしかた |
| --- | --- | --- |
| `souba-items.js` | 品目の一覧。名前・規格・区分（購入／買取／処分）・**相場の目安**・出典・動きのメモ・使う指数コード | 月1回のPRで見直し（手で直してもOK） |
| `souba-trends.js` | 過去の動向（日銀の物価指数・月次、2005年〜） | GitHub Actions が自動更新（手で編集しない） |
| `souba-ads.js` | 広告（AdSense・PR枠・自社PR）と計測の設定 | 手で編集 |

## 毎月の更新のしくみ

| 何を | いつ | どうやって |
| --- | --- | --- |
| 過去の動向（日銀の指数） | 毎週月曜にチェック。新しい月が出ていれば自動で更新・公開 | `.github/workflows/update-souba-trends.yml` |
| 相場の目安（大きい数字） | 毎月20日ごろ | Claude の定期タスクが、各品目の出典を確認し直してPRを作る。中身を見てマージすると公開 |

日銀の企業物価指数は毎月中旬（第8営業日ごろ）、企業向けサービス価格指数（処分費）は下旬に新しい月が出ます。
自動更新を今すぐ動かしたいときは、GitHub の Actions タブで「建材相場 指数の自動更新」を開き、「Run workflow」を押します。

## 過去の動向（指数）を手で最新にする

```bash
node tools/update-souba-trends.mjs
```

Node.js 18 以上があれば追加インストールなしで動きます。`souba-items.js` に書いてある `trend.code` を全部取り直して `souba-trends.js` を作り直します（数字が前回と同じなら書き換えません）。前年比・2020年比・ランキング・トップの前年比は、この数字から自動で計算されます。

## 相場の目安（大きい数字）を直す

`souba-items.js` の各品目の `price` を書き換えます。

```js
price: {
  low: 26000, high: 28000,   // 幅で書く（1つなら同じ値）
  unit: '円/m³',              // 円/t・円/kg・円/枚 など
  basis: '東京17区・協組の販売価格',  // どこの・どういう値段か
  asOf: '2026-10',            // いつ時点か（YYYY-MM か YYYY-MM-DD）
  tax: '税抜',
},
sources: [{ label: '出典の名前', url: 'https://...' }],
```

価格を載せない品目は `price` を消して `priceNote` に一言（例:「直近は2026年4月に+10%の値上げ」）を書きます。
調べ直したら、ファイル先頭の `checkedAt` の日付も更新してください（画面の「PRICE CHECK」に出ます）。

## 広告

設定はすべて `souba-ads.js` にあります。

- **AdSense**：konylog.com と同じサイト運営者IDを使います。広告と計測は konylog.com とそのサブドメインでだけ読み込みます。
  - 自動広告：AdSense 側でオンになっていれば、Google が自動で広告を置きます。
  - 決まった場所に出す：AdSense の管理画面で「ディスプレイ広告」のユニットを作り、`slots` の各場所に `data-ad-slot` の数字を入れます。
- **A8.net**：konylog.com の記事に貼っている A8.net の広告リンク（7件）を流用しています。
  - 詳細画面の「PR」枠：塗料・窯業系サイディング → 外壁塗装の窓口／ヌリカエ、ウレタン塗膜防水 → 防水工事セレクトナビ／街角雨漏り相談所、アルミサッシ・雨どい → 街角雨漏り相談所、コンパネ・石膏ボード → VOICE のレーザー墨出し器
  - ページ内のバナー：品目カードの一覧の下 → 外壁塗装の窓口／ヌリカエ、ランキングの下 → 施工管理技士の通信講座（独学サポート事務局／能セン）
  - **A8.net は登録したサイトにしか広告を貼れません。サブドメインも「副サイト登録」が必要です。** A8 の管理画面で `souba.konylog.com` を副サイトに登録してください。
  - ASP の広告は `aspHosts` に書いたドメインで開いたときだけ出ます（`konylog.vercel.app` では出さず、ミツモリアルの紹介に切り替わります）。
  - 広告を足すときは、A8 の広告コードにある2つの URL を使います。`px.a8.net/svt/ejp?a8mat=…`（広告リンク）は `url` に、`wwwNN.a8.net/0.gif?a8mat=…`（表示回数を数える1×1の画像）は `pixel` に入れます。リンクを2つ並べるときは `links` に書きます。
- **詳細画面の「PR」枠**：品目に合うものを1つ出します（`pr` の上にあるものが優先）。`url` が空の枠は出しません。合うものがない品目には、運営者のサイト（ミツモリアル）の紹介を出します。
- **位置の確認**：URL の最後に `?adpreview=1` を付けると、広告枠の位置と、そこに出る中身が表示されます。リンクと計測はオフになるので、どのドメインでも確認できます。
- **注意**：AdSense の規約で、誤クリックを誘う置き方（ボタンのすぐ近く、メニューや記事と見分けにくい形、「クリックして」と促す文言）は禁止です。違反すると konylog.com も含めて広告が止まることがあるので、枠には必ず「スポンサーリンク」「PR」を表示しておきます。

## 品目を増やす

`items` に1件足すだけです。`trend.code` には日銀「時系列統計データ検索サイト」の系列コードを入れます（例: 生コンクリート = `PRCG20_2200850010`）。
足したあとに `node tools/update-souba-trends.mjs` を1回実行してください。

- `trend.proxy: true` … 品目そのものの指数がなく、値動きが近い指数で代用しているとき（画面に「参考指標」と出ます）
- `trend.link` … 2020年基準の系列が2020年からしかないとき、2015年基準の系列コードを書くと2019年以前をつないで表示します
