# 建材相場ボードのデータ

`souba.html`（建材相場ボード）とトップページの入口パネルが読むデータです。

| ファイル | 中身 | 更新のしかた |
| --- | --- | --- |
| `souba-items.js` | 品目の一覧。名前・規格・区分（購入／買取／処分）・**相場の目安**・出典・動きのメモ・使う指数コード | 手で編集 |
| `souba-trends.js` | 過去の動向（日銀の物価指数・月次、2005年〜） | スクリプトで自動生成（手で編集しない） |

## 過去の動向（指数）を最新にする

日銀の企業物価指数は毎月中旬（第8営業日ごろ）、企業向けサービス価格指数（処分費）は下旬に新しい月が出ます。

```bash
node tools/update-souba-trends.mjs
```

Node.js 18 以上があれば追加インストールなしで動きます。`souba-items.js` に書いてある `trend.code` を全部取り直して `souba-trends.js` を作り直します。前年比・2020年比・ランキング・トップの前年比は、この数字から自動で計算されます。

## 相場の目安（大きい数字）を直す

`souba-items.js` の各品目の `price` を書き換えます。

```js
price: {
  low: 26000, high: 28000,   // 幅で書く（1つなら同じ値）
  unit: '円/m³',              // 円/t・円/kg・円/枚 など
  basis: '東京17区・協組の販売価格',  // どこの・どういう値段か
  asOf: '2026-10',            // いつ時点か（YYYY-MM か YYYY-MM-DD）
  tax: '税抜',
},
sources: [{ label: '出典の名前', url: 'https://...' }],
```

価格を載せない品目は `price` を消して `priceNote` に一言（例:「直近は2026年4月に+10%の値上げ」）を書きます。
調べ直したら、ファイル先頭の `checkedAt` の日付も更新してください（画面の「PRICE CHECK」に出ます）。

## 品目を増やす

`items` に1件足すだけです。`trend.code` には日銀「時系列統計データ検索サイト」の系列コードを入れます（例: 生コンクリート = `PRCG20_2200850010`）。
足したあとに `node tools/update-souba-trends.mjs` を1回実行してください。

- `trend.proxy: true` … 品目そのものの指数がなく、値動きが近い指数で代用しているとき（画面に「参考指標」と出ます）
- `trend.link` … 2020年基準の系列が2020年からしかないとき、2015年基準の系列コードを書くと2019年以前をつないで表示します
